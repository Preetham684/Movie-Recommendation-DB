How it works

Every reply is built from live database results. You can inspect each step in the chat.

  1. 1

    You ask

    Type a question in everyday language, no filters or forms.

  2. 2

    Agent picks a tool

    The LLM works out your intent and chooses one of a few safe, predefined tools.

  3. 3

    Tool runs SQL

    The tool queries PostgreSQL with parameterized joins, filters and sorting.

  4. 4

    You get an answer

    The LLM turns the rows into a clear reply, with the SQL shown if you want it.
